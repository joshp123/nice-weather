Changes: native ERA5 temperature/dew-point cell records; source selection;
common ERA5 monthly-mean adjustment from each source's reference period to
the actual assembled dates; uniform hourly air-temperature shifts using the
average high/low offset; felt-temperature calculations with native dew point,
wind and radiation; quantization to the existing quarter-degree formats.
Build metadata records the exact sources and dates.
